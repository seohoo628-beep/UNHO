# STARZ · 아이스하키팀 플랫폼 🏒

스타즈(STARZ) 아이스하키팀을 위한 올인원 팀 운영 플랫폼입니다.
브라우저만 있으면 바로 쓰며, 값 2개만 넣으면 **팀원과 실시간으로 공유**됩니다.
(설정 전에는 이 브라우저에만 저장하는 개인 모드로 동작합니다.)

![STARZ](assets/logo.jpg)

## 주요 기능

| 메뉴 | 설명 |
|---|---|
| 📊 **대시보드** | 멤버 수 · 이번 달 세션 · 팀 평균 출석률 · 다가오는 일정을 한눈에. 이번 달 **출석왕 랭킹**과 최근 공지도 표시 |
| ✅ **출석체크** | 매주 세션 날짜를 고르고 멤버별로 **출석 / 지각 / 사유 / 결석**을 직접 입력. 전체 출석·전체 결석 일괄 처리 지원 |
| 📅 **월간 출석현황** | 월 단위 대시보드. 인원별 출석률, 개근 인원, 세부 출석표(멤버 × 날짜)를 보여주고 **CSV로 내보내기** 가능 |
| 🏒 **멤버 명단** | 이름 · 나이 · 연락처 · 직업 + 등번호 · 포지션 · 가입일 기록. 검색·수정·삭제 |
| 🗓️ **일정** | 훈련·경기·친선전 일정 관리. 다가오는 일정 / 지난 일정 구분 |
| 📢 **공지사항** | 공지 작성·수정·삭제, 중요 공지 **상단 고정(📌)** |
| 🎬 **자료실** | 경기·훈련 **영상과 사진 업로드**. 카테고리 분류, 미리보기, 원본 다운로드 |

### 그 외 반영한 아이디어
- **출석왕 랭킹** — 이번 달 출석률 기준 자동 순위
- **등번호·포지션** — 명단에 하키 특화 필드 추가
- **개근 인원 / 참석 연인원** 집계
- **CSV 내보내기** — 엑셀·구글시트에서 열어 회비 정산 등에 활용
- **백업/복원** — 데이터를 파일 하나로 저장하고 다른 기기·브라우저로 옮기기

## 사용 방법

### 가장 간단한 방법 (설치 없음)
`public/starz/index.html` 파일을 **더블클릭**해서 브라우저로 열면 끝입니다. (개인 모드)

### 웹 주소로 접속하기 (Vercel)
이 앱은 저장소의 Next.js 앱에 포함되어 배포되므로, 배포 주소 뒤에 **`/starz/`** 를 붙이면 열립니다.
- 예: `https://<배포도메인>/starz/`
- 미리보기(PR): `https://unho-git-<브랜치>-unho.vercel.app/starz/`

## 두 가지 동작 모드

앱 왼쪽 아래에 현재 모드가 표시됩니다.

| | 💾 개인 모드 (기본) | ☁️ 공유 모드 |
|---|---|---|
| 저장 위치 | 접속한 브라우저 안 | 공용 서버(Supabase) |
| 팀원 공유 | ✕ (기기마다 따로) | ✅ 실시간 동기화 |
| 설정 | 필요 없음 | `config.js` 에 값 2개 입력 |

### 공유 모드 켜기 (팀원과 실시간 공유) — 5분
매니저 한 명이 한 번만 설정하면, 이후 팀원은 링크만 열면 같은 데이터를 함께 봅니다.

1. **Supabase 프로젝트 준비** — 이미 운호 플랫폼용 프로젝트가 있으면 **그대로 재사용**하면 됩니다. (없으면 https://supabase.com 에서 무료 생성)
2. **표·버킷 만들기** — Supabase → **SQL Editor** 에서 저장소의 `supabase/starz_setup.sql` 내용을 붙여넣고 **Run**. (한 번만)
3. **열쇠 값 복사** — Supabase → Settings → **API** 에서
   - `Project URL`
   - `anon` `public` 키
4. **config.js 에 붙여넣기** — `public/starz/config.js` 를 열어 두 값을 채우고 저장·배포:
   ```js
   window.STARZ_CONFIG = {
     SUPABASE_URL: "https://xxxx.supabase.co",
     SUPABASE_ANON_KEY: "eyJhbGci...",
   };
   ```
5. 끝! 새로고침하면 왼쪽 아래가 **☁️ 공유 모드 · 실시간** 으로 바뀝니다.

> **보안 안내**: `anon` 키는 브라우저에 공개되도록 설계된 값이라 넣어도 안전합니다. 다만 이 설정은 *링크와 키를 아는 사람은 데이터를 보고 수정할 수 있는* 팀 내부용 공개 모드입니다. **팀 내부에서만 링크를 공유**하세요. 더 엄격한 로그인 기반 접근이 필요하면 확장 가능합니다.

## 데이터·백업

- 개인 모드: 브라우저(localStorage + IndexedDB)에 저장. 브라우저 기록을 지우면 사라지므로 **"백업 저장"** 으로 정기 백업 권장.
- 공유 모드: Supabase에 저장되어 기기·팀원 간 공유. 백업 기능은 두 모드 모두에서 전체 데이터를 파일 하나로 내려받습니다.

## 기술
순수 HTML · CSS · JavaScript (프레임워크·빌드 없음). 저장 계층이 개인/공유 모드를 자동 판별합니다.

```
public/starz/
├── index.html
├── config.js       # 공유 모드 설정 (URL/KEY) — 비우면 개인 모드
├── css/styles.css
├── js/
│   ├── db.js       # 이중 백엔드 어댑터 (localStorage/IndexedDB ↔ Supabase + 실시간)
│   └── app.js      # 화면·로직
└── assets/logo.jpg

supabase/starz_setup.sql   # 공유 모드용 1회 설치 SQL
```
