# 네이버 블로그 반자동 포스팅

## 원칙

- **발행은 사람이 한다.** Claude는 글 작성 + 에디터 입력 + 임시저장까지만.
  발행·예약발행 버튼을 자동 클릭하지 않는다 (계정 제재 위험).
- 하루 2건 이상 연속 입력하지 않는다. 여러 편이 필요하면 초안 파일로 만들어 두고
  하루에 나눠 입력한다.
- 광고성 문구(화장품·건강기능식품·의료)는 입력 전에 표시광고 규제 기준으로
  자체 검수한다. 검수 걸리는 표현은 수정 후 진행한다.

## 절차

1. **글 작성** — 주제·브랜드를 확인하고 SEO를 고려해 작성한다.
   - 제목: 핵심 키워드 앞배치, 25자 내외
   - 본문: 도입(공감 질문) → 소제목 3~5개 → 마무리(요약+CTA)
   - 1,500자 이상, 키워드 3~5회 자연 배치, 과장·확정 표현 금지
2. **브라우저 확인** — Playwright MCP로 `https://blog.naver.com` 접속.
   로그인이 풀려 있으면 로그인 페이지를 띄우고 사용자에게 직접 로그인을 요청한 뒤
   대기한다 (아이디/비밀번호를 대신 입력하지 않는다).
3. **에디터 열기** — `https://blog.naver.com/<블로그ID>?Redirect=Write&` 로 이동.
   이전 작성 글 복구 팝업이 뜨면 사용자에게 물어보고 처리한다.
4. **입력** — 제목 영역 클릭 후 제목 입력, 본문 영역 클릭 후 문단 단위로 입력한다.
   붙여넣기가 막히면 `browser_type` 으로 문단씩 타이핑한다.
5. **임시저장** — 에디터의 "저장" 버튼을 눌러 임시저장하고, 스크린샷을 찍어
   사용자에게 확인시킨다.
6. **종료 보고** — "입력 완료. 사진 추가와 발행은 직접 해주세요"로 마친다.
   이미지가 준비되어 있으면 어느 위치에 넣을지 본문에 `[이미지: 설명]` 표시를 남긴다.

## 시리즈 운영

"블로그 10편 뽑아줘" 류 요청은 에디터 입력 없이 초안 마크다운 파일 10개를
`~/unho-automation/blog-drafts/` 에 저장하고 목차만 보고한다. 이후 "오늘 것 올려줘"
때 1편씩 위 절차로 입력한다.
