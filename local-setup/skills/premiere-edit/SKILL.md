# 프리미어 프로 편집 자동화

## 사전 조건

- Premiere Pro가 실행 중이고, `창(Window) → 확장(Extensions)` 의 MCP Bridge
  패널이 열려 있어야 한다. 연결이 안 되면 이 두 가지부터 확인시킨다.
- 편집 대상 프로젝트가 열려 있어야 한다. 새 작업이면 프로젝트 생성부터 한다.

## 안전 수칙

- **원본 파괴 금지.** 작업 시작 전 프로젝트를 저장하게 하고, 큰 변경(전체 재배열,
  대량 삭제) 전에는 시퀀스를 복제해 사본에서 작업한다.
- 내보내기(익스포트)는 설정(포맷·해상도·저장 경로)을 보고한 뒤 실행한다.
- 렌더·내보내기는 오래 걸릴 수 있다. 완료를 기다렸다가 결과 파일 경로를 보고한다.

## 표준 작업 흐름

1. **상태 파악** — 열린 프로젝트, 시퀀스, 빈(bin) 구조를 먼저 조회해 보고한다.
2. **임포트** — 사용자가 준 폴더/파일 경로의 미디어를 프로젝트에 임포트한다.
3. **편집 실행** — 요청을 구체 작업으로 쪼개 순서대로 실행한다:
   - 컷편집: 클립을 타임라인에 배치, 인/아웃 조정, 무음·NG 구간 컷
   - 오디오: 배경음악 트랙 추가, 볼륨 조정, 오디오 덕킹
   - 자막: 캡션 트랙 생성 또는 텍스트 레이어 추가
   - 릴스/숏폼: 9:16 시퀀스(1080×1920) 기준
4. **중간 확인** — 편집 단계가 끝날 때마다 무엇이 어떻게 바뀌었는지 요약 보고한다.
5. **내보내기** — 용도별 프리셋: 릴스·숏폼은 H.264 1080×1920, 유튜브는
   H.264 1920×1080. 저장 경로는 `~/unho-automation/exports/` 기본.

## 운호컴퍼니 숏폼 기본 규격

- 세로 9:16, 30~60초, 첫 3초 후킹 컷 필수
- 자막은 화면 하단 1/3, 안전 영역(상하 250px) 침범 금지
- 브랜드 계정별 대본은 릴스 대본 워크플로우(reels-script)가 만든 것을 따른다
