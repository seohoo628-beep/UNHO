# 스피듀얼샷 LDM 블로그 캠페인 (리앤밤)

목표: 네이버에서 **"LDM 디바이스" / "미용디바이스"** 키워드 상위노출 + 스피듀얼샷 브랜딩.

## 동작 구조 (반자동 — 발행만 사람이)

```
매일 08:30  작업 스케줄러가 Claude 실행
          → strategy.md + calendar.md 를 읽고 오늘 원고 작성
          → 네이버 블로그 에디터에 제목·본문 입력 → 임시저장
사장님     열어서 확인 → 사진 넣고 → 발행 버튼 클릭 (약 1분)
```

완전 무인 발행을 하지 않는 이유: 네이버 스팸 필터는 기계 발행 패턴(정각 발행,
무사진, 동일 구조 반복)에 민감하다. 상위노출이 목표라면 사람 손이 마지막에
닿는 지금 구조가 가장 안전하고 효과적이다.

## 설치 (한 번만)

PowerShell에서:

```powershell
cd C:\Users\MYCOM\Downloads\UNHO\local-setup\blog-campaign
Set-ExecutionPolicy -Scope Process Bypass
.\register-daily-task.ps1
```

매일 08:30에 Claude 창이 자동으로 뜬다. 시간을 바꾸려면
`register-daily-task.ps1` 안의 `08:30` 을 수정하고 다시 실행.
해제: `Unregister-ScheduledTask -TaskName "UNHO Daily Blog Draft"`

## 시작 전 준비물 (중요)

1. **제품 정보 채우기** — `strategy.md` 의 `【확인 필요】` 항목(스펙, KC 인증,
   가격, 스토어 링크)을 실제 값으로 채운다. 채우기 전까지 원고에는 해당 내용이
   비워진 채 나온다. 원고에 없는 스펙을 지어내는 것은 금지되어 있다.
2. **제품 사진 준비** — 상위노출에는 직접 찍은 사진이 필수다.
   `photos/` 폴더에 제품컷·사용컷을 넣어두면 원고에 삽입 위치가 표시된다.
3. 시작용 원고 3편이 `drafts/` 에 있다. 스케줄러 등록 전에 오늘 당장
   1편을 올리고 싶으면 로컬 Claude에게 "drafts/day01.md 네이버 에디터에
   넣어줘"라고 하면 된다.

## 상위노출에 대한 솔직한 안내

- 신규/저지수 블로그가 "미용디바이스" 같은 대형 키워드에 오르려면 통상
  2~3개월 이상 꾸준함이 필요하다. 그래서 캘린더는 경쟁이 낮은 롱테일
  키워드부터 잡아 지수를 쌓고 메인 키워드로 확장하는 순서로 짜여 있다.
- 매일 같은 키워드 반복은 유사문서로 묶여 역효과다. 캘린더가 주제와
  키워드를 매일 다르게 배치하는 이유다.
- 4주마다 순위·유입 리포트를 요청해서 (예: "블로그 성과 정리해줘")
  캘린더를 조정할 것.
