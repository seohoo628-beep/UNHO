# 운호 F&B 매장 통합관리 플랫폼

운호컴퍼니 F&B 매장(**청담 오리닭**, **은우 더 블랙**) 운영을 한 곳에서 관리하는 웹 플랫폼입니다.
기존 운호컴퍼니 운영 플랫폼과 **별개**로 신설된 앱으로, 이 저장소의 `fnb-platform/` 폴더에 독립적으로 존재합니다.

## 주요 기능

| 메뉴 | 내용 |
| --- | --- |
| **대시보드** | 매출·영업이익·예약·발주 필요 등 통합 KPI, 매장별 요약 |
| **운영기획** | 월간 목표 달성 현황, 운영 액션플랜(예정/진행중/완료 보드) |
| **직원관리** | 직원 명부, 고용형태·급여, 오늘 근무표, 월 인건비 추정 |
| **예약관리** | 일자별 예약 현황, 상태(확정/대기/착석/취소/노쇼) 관리 |
| **식자재관리** | 재고·발주점 관리, 부족 품목 원클릭 발주(PO), 입고 시 재고 자동 반영 |
| **마케팅관리** | 캠페인/채널별 집행·전환·CPA, 예산 소진 현황 |
| **P&L 관리** | 월별 손익계산서, 원가율·인건비율·영업이익률, 매출/이익 추이, 비용 구성 |
| **전달사항** | 본사·매장 간 공지, 중요도·고정 기능 |

상단에서 **전 매장 / 청담 오리닭 / 은우 더 블랙**을 전환하면 모든 화면이 해당 범위로 필터링됩니다.

## 기술 스택

- **Next.js 14** (App Router) · **React 18** · **TypeScript**
- 외부 UI/차트 라이브러리 없음 — 순수 CSS 디자인 시스템(라이트·다크 자동)
- 데이터는 **시드데이터 + 브라우저 localStorage**로 동작 (외부 DB 불필요)
  - 추가/수정/삭제한 내용은 브라우저에 저장됩니다.
  - 상단 **↺ 초기화**로 예시 데이터로 되돌릴 수 있습니다.
  - 추후 Supabase 등 실 DB 연동으로 교체 시 `src/lib/store.tsx`의 저장 계층만 바꾸면 됩니다.

## 실행

```bash
cd fnb-platform
npm install
npm run dev      # http://localhost:3100
```

기타 스크립트:

```bash
npm run build      # 프로덕션 빌드
npm run start      # 프로덕션 서버 (포트 3100)
npm run typecheck  # 타입 검사
```

## 폴더 구조

```
fnb-platform/
├── src/
│   ├── app/
│   │   ├── layout.tsx           # 루트 레이아웃(사이드바+상단바+데이터 프로바이더)
│   │   ├── page.tsx             # 대시보드
│   │   ├── operations/          # 운영기획
│   │   ├── staff/               # 직원관리
│   │   ├── reservations/        # 예약관리
│   │   ├── ingredients/         # 식자재관리
│   │   ├── marketing/           # 마케팅관리
│   │   ├── pnl/                 # P&L 관리
│   │   └── announcements/       # 전달사항
│   ├── components/              # Sidebar, Topbar, 공용 UI
│   └── lib/
│       ├── types.ts             # 도메인 타입
│       ├── stores.ts            # 두 매장 정의
│       ├── seed.ts              # 시드(예시) 데이터
│       ├── store.tsx            # 상태관리(Context + localStorage)
│       ├── pnl.ts               # 손익 파생 계산
│       ├── format.ts            # 숫자/통화 포맷
│       └── nav.ts               # 네비게이션 정의
└── ...
```

## 데이터 모델 확장

새 매장을 추가하려면 `src/lib/stores.ts`의 `STORES` 배열과 `src/lib/types.ts`의 `StoreId`에 항목을 더하면 됩니다.
새 관리 항목(모듈)은 `types.ts`에 타입 → `seed.ts`에 시드 → `src/app/<메뉴>/page.tsx` 페이지 → `nav.ts`에 메뉴 순으로 추가합니다.
