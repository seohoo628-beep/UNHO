# STARZ · 아이스하키팀 플랫폼 🏒

스타즈(STARZ) 아이스하키팀을 위한 올인원 팀 운영 플랫폼입니다.
**설치·서버·회원가입 없이** 브라우저만 있으면 바로 씁니다.

![STARZ](assets/logo.jpg)

## 주요 기능

| 메뉴 | 설명 |
|---|---|
| 📊 **대시보드** | 멤버 수 · 이번 달 세션 · 팀 평균 출석률 · 다가오는 일정을 한눈에. 이번 달 **출석왕 랭킹**과 최근 공지도 표시 |
| ✅ **출석체크** | 매주 세션 날짜를 고르고 멤버별로 **출석 / 지각 / 사유 / 결석**을 직접 입력. 전체 출석·전체 결석 일괄 처리 지원 |
| 📅 **월간 출석현황** | 월 단위 대시보드. 인원별 출석률, 개근 인원, 세부 출석표(멤버 × 날짜)를 보여주고 **CSV로 내보내기** 가능 |
| 🏒 **멤버 명단** | 이름 · 나이 · 연락처 · 직업 + 등번호 · 포지션 · 가입일 기록. 검색·수정·삭제 |
| 🗓️ **일정** | 훈련·경기·친선전 일정 관리. 다가오는 일정 / 지난 일정 구분 |
| 📢 **공지사항** | 공지 작성·수정·삭제, 중요 공지 **상단 고정(📌)** |
| 🎬 **자료실** | 경기·훈련 **영상과 사진 업로드**. 카테고리 분류, 미리보기, 원본 다운로드 |

### 그 외 반영한 아이디어
- **출석왕 랭킹** — 이번 달 출석률 기준 자동 순위
- **등번호·포지션** — 명단에 하키 특화 필드 추가
- **개근 인원 / 참석 연인원** 집계
- **CSV 내보내기** — 엑셀·구글시트에서 열어 회비 정산 등에 활용
- **백업/복원** — 데이터를 파일 하나로 저장하고 다른 기기·브라우저로 옮기기

## 사용 방법

### 가장 간단한 방법 (설치 없음)
`starz/index.html` 파일을 **더블클릭**해서 브라우저로 열면 끝입니다.

### 웹에 올려서 팀원과 공유하기
`starz` 폴더를 정적 호스팅에 올리면 링크로 접속할 수 있습니다.
- **GitHub Pages**: 저장소 Settings → Pages → 브랜치 지정 후 `/starz/` 경로로 접속
- **Netlify / Vercel**: `starz` 폴더를 드래그 앤 드롭

## 데이터는 어디에 저장되나요?

- 모든 데이터는 **접속한 브라우저 안(localStorage + IndexedDB)** 에 저장됩니다.
- 서버가 없으므로 **개인정보가 외부로 전송되지 않습니다.**
- 단, 브라우저 데이터를 지우면 사라지므로 **왼쪽 아래 "백업 저장"** 으로 정기 백업을 권장합니다.
- 여러 사람이 각자 입력한 내용을 실시간으로 공유하려면 별도의 공용 서버(예: Supabase)가 필요합니다. 필요하면 확장 안내를 드릴 수 있습니다.

## 기술
순수 HTML · CSS · JavaScript (프레임워크·빌드 없음). 사진/영상은 용량이 크므로 IndexedDB에 저장합니다.

```
starz/
├── index.html
├── css/styles.css
├── js/
│   ├── db.js      # 저장 계층 (localStorage + IndexedDB + 백업)
│   └── app.js     # 화면·로직
└── assets/logo.jpg
```
